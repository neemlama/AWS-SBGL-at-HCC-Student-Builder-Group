## Structure

```
aws-student-builder-group/
├── README.md
├── events/               # one folder per event (date + topic)
├── workshops/            # hands-on labs, slides, code
├── projects/             # member builds
├── resources/            # links from Box kit + AWS resources
└── impact/               # metrics, reports, Best-in-Class
```
